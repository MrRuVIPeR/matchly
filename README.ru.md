# allowly

[en](README.md)
[ru](README.ru.md)


Минималистичная библиотека для проверки строковых значений по набору гибких правил: разрешающие, запрещающие, шаблоны, маски и регулярные выражения.

Подходит для валидации конфигов, фильтрации входных данных, маршрутизации и любых систем с rule-based доступом.

---

## Возможности

* Полное совпадение (`"value"`)
* Глобальное разрешение (`"*"`)
* Исключения (`!value`, `!value*`)
* Частичное совпадение по шаблону:

  * начинается с (`value*`)
  * заканчивается на (`*value`)
  * содержит (`*value*`)
* Экранирование спецсимволов (`\*`, `\!`, `\/`)
* Поддержка RegExp (`/pattern/i`)

---

## Установка

```bash
npm install allowly
```

---

## Использование

```ts
import allowly from "allowly";

allowly("admin", ["*"]);               // true
allowly("admin", ["!admin"]);           // false
allowly("superadmin", ["admin*"]);      // true
allowly("user-42", ["/user-\\d+/i"]);  // true
```

## Параметры

```js
  allowly(value: string, rules: string[], options: Partial<WhitelistOptions> = { strict: true, caseSensitive: false })
```
* `strict: boolean` - строгий режим
* `caseSensitive: boolean` - режим с учётом регистра

## Правила

### 1. Полное совпадение

```ts
["value"] → подходит только "value"
```

### 2. Глобальное разрешение

```ts
["*"] → разрешено всё
```

### 3. Исключения

```ts
["!value"] → запрещает "value"
["!value*"] → запрещает всё, что начинается с "value"
```

### 4. Частичное совпадение (wildcards)

```ts
["value*"]   → начинается с
["*value"]   → заканчивается на
["*value*"]  → содержит
```

### 5. Экранирование

```ts
["\\*"] → символ "*"
["\\!"] → символ "!"
["\\/"] → символ "/"
```

### 6. Регулярные выражения

```ts
["/foo/i"] → регэксп с флагами
["/^user-\\d+$/"] → строгий RegExp
```
